ARCHITECTURE

GCS Buckets → Bucket Notifications → Pub/Sub → listener.py → PostgreSQL → Batch Creator → Docker Worker Pool (10-100 Workers) → rclone → Azure Blob

Rollback Flow:

Azure Blob → Event Grid → Azure Storage Queue → rollback_listener.py → PostgreSQL → Rollback Batch Creator → Docker Rollback Worker Pool (10-100 Workers) → rclone → GCS

Failed Flow:

Pub/Sub → DLQ Topic → DLQ Subscription

PHASE 1 - CONFIGURE DLQ

Create DLQ Topic

Create DLQ Subscription

gcloud pubsub subscriptions create gcs-dlq-sub --topic=gcs-dlq

gcloud pubsub subscriptions update gcs-azureblob-sync --dead-letter-topic=gcs-dlq --max-delivery-attempts=5

22. AUTOSCALING SCRIPT

Create:

Shell
nano autoscale.sh
Shell
#!/bin/bash
 
PENDING=$(psql -d gcssync -t -c "
SELECT COUNT(*)
FROM sync_batches
WHERE status='PENDING';
")
 
if [ $PENDING -lt 100 ]
then
docker compose up -d --scale worker=10
 
elif [ $PENDING -lt 1000 ]
then
docker compose up -d --scale worker=25
 
elif [ $PENDING -lt 5000 ]
then
docker compose up -d --scale worker=50
 
else
docker compose up -d --scale worker=100
 
fi
